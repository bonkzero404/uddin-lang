## 🚀 Quick Start

To run any of these examples:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/bonkzero404/uddin-lang.git
   cd uddin-lang
   ```

2. **Navigate to examples:**
   ```bash
   cd examples
   ```

3. **Run an example:**
   ```bash
   go run main.go examples/basics/hello_world.din
   ```
